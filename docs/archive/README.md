# Historical project documents

These are unchanged copies of the nine user-supplied planning/review documents.
They preserve provenance and useful implementation detail.

They are not all current instructions. In particular, older unwound M_CONSTR
and generic FRAME_MINT assumptions, OUTCAR-based realization, and angular model
state have been superseded by math Revision 2.4 and the Step 1 spec.

The code inventory describes a September 15 checkout. It does not establish
the present code's paths, bugs, test results or completion status.
Later preflight/next-step notes correct some earlier review proposals.

Read the current spec first. Consult these records for historical reasons and
unchanged campaign requirements; do not import their acceptance labels as new
production evidence. Preserve these snapshots, and record current instructions
outside this directory.
