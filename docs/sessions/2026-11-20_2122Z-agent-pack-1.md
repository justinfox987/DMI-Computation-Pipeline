## Decisions or deviations

Not covered by the design, and chosen here (also in the spec):

1. **Failure accounting.** `wait -n` only throttles; failures are recorded in a
   `mktemp` file, then a plain `wait` runs, so the result does not depend on
   the bash version.
2. **Short forms.** `-t` and `-G` are accepted like `-N`.
3. **`--gpus=type:N`.** The type is kept, and N is scaled.
4. **Refusals.** An option set twice, or a non-integer node or GPU count, is
   refused. `-N2` with no separator is not recognised, so the job is refused as
   having no `--nodes`.
5. **`--max-time`.** It is refused without `--slots`.
6. **Other header lines.** `--ntasks`, `--mem` and the like are copied
   unchanged; the docs say to give them per node.
7. **The contract check is textual.** `DMI_RUN_NODES` and `--exact` must appear
   in the body, so a comment would satisfy it.
